# Quant Dossier

A comprehensive quantitative research and portfolio platform featuring market-making labs, options pricing engines, and statistical arbitrage research tools.

## Project Structure

- **docs/** - Design specifications, roadmap, and workflow documentation
- **tickets/** - Project management tickets and task descriptions
- **src/** - Next.js application with pages and components
- **quant/** - Quantitative research modules and engines
- **public/** - Static assets and documentation

## Quick Start

```bash
pnpm install
pnpm dev
```
